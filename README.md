### Memory & AI

How does a memory tell when a rule has been superseded?
How do many agents write to the same memory without contradicting each other?
How do you record why a decision was made?

<p align="center">
  <img src="assets/memory.gif" width="640" alt="People and AI agents read and write the same memory. A person updates a rule. The old rule turns red and leaves the memory. Then an agent asks a question. The answer cites the new rule and traces it back to the person who wrote it.">
</p>

### Custom ontologies for AI

An ontology is the basis on which a system draws inferences.
It is a formal specification of a shared conceptualisation.
It defines the classes, relations and axioms of a domain.

How do you build an ontology?
How do you update it when the company changes the way it works?
How does an agent use it to reason and not only to search?

<p align="center">
  <img src="assets/ontology.gif" width="720" alt="Fragments come out of unstructured text and become entities of three classes. Relations of two kinds link them. Then new information arrives and an old relation gives way to a new one. An agent asks a question and its search follows the relations. Where a direct link is missing, the system infers it from two existing relations. The search goes on along the inferred relation and reaches the answer.">
</p>
